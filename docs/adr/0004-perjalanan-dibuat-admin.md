# Perjalanan Dinas dibuat oleh Admin, bukan Pegawai

Hanya Admin Kepegawaian (dan Super Admin) yang boleh membuat dan menyunting Perjalanan Dinas. Pegawai tidak mengajukan sendiri; perannya adalah melihat kalender/riwayat, mengisi Laporan Perjalanan, dan mengunggah Dokumentasi.

Ini menyimpang dari pola self-service yang umum, tetapi dipilih karena penugasan perjalanan di instansi berasal dari keputusan pimpinan dan anggaran, bukan usulan pegawai. Konsekuensinya, beban input ada di Admin, dan setiap koreksi data perjalanan harus melalui Admin. Bila kelak pegawai perlu mengusulkan perjalanan, perlu ditambahkan status pengajuan tersendiri agar tidak mencampur usulan dengan penugasan resmi.
